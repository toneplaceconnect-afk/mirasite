# Mira: контекст проекта

Сайт: https://mira.compilepoint.space/ (Vercel, проект `mirasite`, репозиторий `toneplaceconnect-afk/mirasite`).
Домен `compilepoint.space` у Хостингера, поддомен `mira` подключён CNAME-записью на Vercel.
Секреты хранятся только в переменных окружения Vercel, в чат и в репозиторий не попадают.

## Принятые решения

- Mira говорит от своего имени. Владелец для Mira: Compile Point.
- На сайте и в ответах Mira нет цен и цифр.
- Акция: Mira бесплатна до конца 2026 года. Бесплатен только код Mira. ИИ-провайдера оплачивает клиент.
  В инструкции по подключению клиент получает платный и бесплатные способы подключить ИИ-провайдера.
- Mira не обсуждает процессы создания и подключения (они ещё не определены).
- У Mira собственные знания и собственный контракт. Контракт и знания Compile Point не переносятся.
- Формы связи на сайте нет. Обращение передаётся одной кнопкой в Telegram-бота владельца.
  Mira сама спрашивает у посетителя контакт в диалоге, потому что Telegram есть не у всех.
- Из контактов на сайте только иконка ВКонтакте: https://vk.ru/compilepoint
- Новых блоков на сайте не добавляем. Блоки: первый экран, «Кому нужна», «Как работает», «Где работает», финал.
- Текст на сайте не мельче 13px. Стрелки у ссылок и кнопок не используются. Знак ® не используется.
- Шрифт Manrope лежит в `public/fonts` (свой хостинг, без Google Fonts, лицензия OFL).

## Переменные окружения (Vercel → Settings → Environment Variables)

Уже заданы: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `GROQ_API_KEY`, `NVIDIA_API_KEY`, `GITHUB_TOKEN`.
На потом: `ADMIN_PASSWORD`, `ADMIN_SECRET`.
Сейчас `api/chat.js` ждёт `OPENAI_API_KEY`. Без него чат работает в демонстрационном режиме.

## Структура

- `index.html`, `src/*.css`, `src/*.js`: страница и анимации (Vite).
- `Mira.html`: анимированный персонаж, подключается в iframe, закрыт от индексации.
- `api/chat.js`: чат. `api/lead.js`: передача обращения в Telegram.
- `public/`: шрифты, иконки, `og.png`, `robots.txt`, `sitemap.xml`.
- `vercel.json`: сборка, заголовки, `X-Robots-Tag: noindex` для `Mira.html`.

## План

1. Контракт и знания Mira (свои, с нуля).
2. Подключение чата к провайдерам Groq и NVIDIA вместо OpenAI, проверка качества ответов.
3. Процесс подключения Mira клиентом: скачал, подключил, проверил. Тестовый режим.
4. Варианты цветов робота.
5. Админка.
