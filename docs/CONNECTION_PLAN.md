# План: подключение Mira клиентом (черновик до разработки)

## Принцип
Клиент скачивает набор, подключает одной строкой на сайт и сам проверяет, что всё работает. Код Mira бесплатен (акция до конца 2026), ИИ-провайдер оплачивает клиент — об этом клиент узнаёт ДО установки. На сайте Mira цен и цифр нет.

## Что в наборе
1. `mira.js` — виджет: одна строка `<script src=... data-color="mint" data-position="right" data-greeting="...">` перед `</body>`.
2. Серверная часть (на основе `api/chat.js`, `api/lead.js`, `lib/mira.js`): чат, провайдеры, защита, передача обращения.
3. `knowledge/*.md` — шаблоны знаний, клиент правит под своё дело.
4. `.env.example`: ключ ИИ-провайдера, Telegram-бот и/или webhook для обращений, `ALLOWED_ORIGINS` (белый список доменов).
5. Страница «Проверка» (`/check`): сервер жив, знания загружены, провайдер отвечает (имя, модель, время), домен разрешён, тестовое сообщение.
6. Страница «Песочница»: чат с Mira + выбор цвета/положения, видно, что получит посетитель.

## Пути установки (по сложности)
- A. Vercel: кнопка «развернуть», ввод ключей, готово. (первый релиз)
- B. VPS: Node/Docker, одна команда.
- C. Позже: PHP-версия для обычного хостинга и WordPress (в РФ часто именно он).
Инструкции по платформам: WordPress, Tilda, Битрикс, Google Tag Manager/Яндекс Метрика-теги.

## ИИ-провайдер: что узнаёт клиент
- Платный провайдер нужен почти всегда; бесплатные тарифы есть, но с лимитами.
- Важно: расположение сервера. Зарубежные провайдеры могут быть недоступны с российского хостинга; для РФ — отечественные (GigaChat, YandexGPT) или совместимые шлюзы.
- Бесплатные варианты (проверять актуальность перед публикацией): OpenRouter `:free`, Groq, Cerebras, Cloudflare Workers AI, GigaChat для физлиц.
- Мастер выбора в инструкции: «где у вас хостинг» → «какой провайдер» → «куда вписать ключ».

## Тестирование (для владельца)
Страница «Проверка» + `npm test` + `npm run eval` (сценарии из `content/eval`). Цвета Mira: `Mira.html?color=cyan|mint|violet|rose|amber`.

## Решения, которые нужны от владельца
1. Первый релиз: Vercel/Node (рекомендую) или сразу PHP.
2. Распространение: публичный шаблон на GitHub или скачивание с сайта (с запросом контакта).
3. Лицензия набора после акции.
